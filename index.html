Setup Shared Cloud Database

By default, SATA Split stores everything locally in your browser (LocalStorage). To enable real-time collaboration with friends via a shared link, connect the app to a free Google Firebase Firestore database:

1. Create a Firebase Project

Go to the Firebase Console, sign in with your Google account, and click "Create a project". Follow the prompts (Google Analytics is optional).

2. Set up Firestore Database

In the project sidebar, go to Firestore Database and click "Create database".

Choose "Start in test mode" (allows reading/writing without login setup) and select a location, then click enable.

3. Register a Web App

On your Firebase Project Overview page, click the web icon (</>) to register an app. Name it "SATA Split".

Copy the firebaseConfig object containing your apiKey, projectId, etc.

4. Update Your Configuration Code

Open the file config.js in your project, uncomment the configuration block, and paste your values there.

5. Push to GitHub

Commit your files and publish your repository to GitHub. Enable GitHub Pages in the repository settings to deploy the application. Anyone opening that link can now sync expenses collaboratively!

⚙️ Gemini AI Setup

To enable real receipt scanning, enter your free Gemini API Key from Google AI Studio. The key is saved locally in your browser.

Don't have one? Get it free from Google AI Studio.
